# CampusHub: duplicate booking

Ovo je završni izazov. Korisnici prijavljuju da isti student ponekad može da rezerviše isti događaj više puta. Istražite source, testove i log, pa podržite zaključak dokazima.

Pokretanje iz ovog direktorijuma:

```bash
python -m pytest -q
```

Očekujte da test koji reprodukuje prijavljeni problem trenutno ne prođe. Nemojte menjati fajlove tokom prvog istraživanja.
